Your 5 learning phases

Build foundations first, then apply them to a fintech business problem.

Days 1–10 · 19–28 Nov

01 · Excel

Clean, analyse and summarise data.

  • Formulas: SUM, IF, COUNTIFS, SUMIFS
  • XLOOKUP / VLOOKUP
  • Sorting, filtering and data cleaning
  • Pivot Tables, charts and slicers
  • Build a sales and transaction workbook
Days 11–25 · 29 Nov–13 Dec

02 · SQL

Query relational data independently.

  • SELECT, WHERE, ORDER BY
  • GROUP BY, HAVING and aggregates
  • INNER / LEFT JOIN
  • CASE WHEN, subqueries and CTEs
  • Dates, ranking and business questions
Days 26–39 · 14–27 Dec

03 · Power BI

Turn data into useful business insights.

  • Import Excel / CSV data
  • Power Query and data modelling
  • Relationships and star schema basics
  • DAX measures and filter context
  • Build an interactive dashboard
Days 40–47 · 28 Dec–4 Jan

04 · APIs & Postman

Understand how applications communicate.

  • REST, HTTP methods and status codes
  • JSON, headers and parameters
  • GET and POST requests in Postman
  • Authentication concepts and errors
  • Write API test cases and requirements
Days 48–60 · 5–17 Jan

05 · Portfolio & interviews

Demonstrate what you can do.

  • Create a synthetic fintech dataset
  • Analyse it with SQL and Excel
  • Build a Power BI report
  • Document requirements and user stories
  • Practise technical and behavioural interviews
Throughout all 60 days

06 · Career development

Keep your job search moving.

  • Update resume and LinkedIn
  • Apply to relevant junior BA / product roles
  • Record project evidence and achievements
  • Explore master's pathways for 2028

Portfolio projects

Use fictional or properly licensed public data. Never use confidential employer or customer records.

Project 1 · Days 7–10

Sales & Revenue Analysis in Excel

Create a fictional dataset and analyse monthly sales, product performance, revenue growth and customer activity.

  • Clean data and validate missing / duplicate records.
  • Use formulas, lookups and Pivot Tables.
  • Create charts and a summary dashboard.
Project 2 · Days 48–56

FinTech Investment Operations Analytics

Analyse synthetic SIP transactions, payment outcomes, active investors and monthly investment volume.

  • Write SQL queries to answer business questions.
  • Prepare an Excel validation and analysis sheet.
  • Build an interactive Power BI dashboard.
  • Write a short BRD, user stories and acceptance criteria.
  • Prepare a short project walkthrough.

Portfolio checklist





Interview preparation

Practise explaining concepts in your own words. Don't memorise answers without understanding them.

Excel

When would you use XLOOKUP instead of VLOOKUP?
How do Pivot Tables help a business analyst?
How would you identify duplicate transactions?

SQL

What is the difference between WHERE and HAVING?
Explain INNER JOIN versus LEFT JOIN.
How would you find the top five customers by investment amount?
How would you calculate monthly transaction success rates?

Power BI

What is the difference between a measure and a calculated column?
What is Power Query used for?
How would you explain a dashboard to a nontechnical stakeholder?

Business Analysis

How do you gather requirements from stakeholders?
What makes a good user story?
How would you handle changing requirements during a sprint?
Describe a feature you helped deliver.

Behavioural

Tell me about yourself.
Why are you looking for a new opportunity?
Describe a disagreement with a stakeholder.
What technical skills have you recently learned?
Be transparent in interviews: distinguish your professional experience from skills and projects you have developed independently. Never claim professional SQL or Power BI experience unless you have actually used them at work.
